# Política de segurança

A versão atualmente suportada é a **2.5**.

Para relatar uma vulnerabilidade, prefira um canal privado, como **GitHub Security Advisory / Report a vulnerability**, quando disponível no repositório. Não publique tokens, App Secret, Refresh Token, nomes de clientes, caminhos de backup ou relatórios em uma Issue pública.

Se uma credencial tiver sido exposta, considere-a comprometida: revogue/rotacione a credencial no provedor correspondente antes de qualquer outra ação.

Os controles técnicos e riscos residuais do projeto estão documentados em [`docs/06_SEGURANCA.md`](docs/06_SEGURANCA.md).
